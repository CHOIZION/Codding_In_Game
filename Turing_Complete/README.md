# Turing_Complete

16번부터는 난이도가 급 상승하는 관계로 가능하면 표도 같이 이미지에 넣는 중.

컴퓨터 구조 복습할 겸 공부




3일차 / CPU 아키텍처 푸쉬하면서 폴더 번호가 한칸씩 밀렸음.
폴더 자체에 이미지 파일은 맞게 넣었으니 이름은 무시하고 보면 됨.

중간에 보면 번호 안달린 어셈블리 폴더도 하나 추가 됐음.

Turing_Complete 중간 부분에 어셈블리를 사용하여 문제를 푸는 게 있는데
필자는 어셈블리에 대해 잘 모르기도 하고, C 언어로 작성한 뒤 하나하나 번역해서 작성하자니 너무 귀찮아 AI의 도움을 좀 받았음.

따라서 중간 부분 문제 풀이 폴더는 통째로 건너뛰고 어셈블리 폴더 하나로 통합한거임.

안에는 readme 파일 하나만 있을텐데

Turing_Complete 안에 있는 메뉴얼을 하나하나 읽어보며 필자가 나름대로 이해한 느낌을 글로 적어둔 것이니

어셈블리 파트 문제 풀이에 어려움이 있을 때 보면 도움이 될지도...? 모름.
